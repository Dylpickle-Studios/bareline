Paper Trail

A small, durable record of decisions. Designed for quiet, deliberate work.

Interactive local demo. Browse and change a seeded repository in your browser — import a patch with a real dry-run preview, fork, merge, cherry-pick, revert, edit the wiki, publish a release, and file an issue. Cloning, pushing, accounts, and server search require the self-hosted server.

The essentials, carefully made

Everything you need to live comfortably in Git.

Repository browsing

File trees, rendered README files, syntax-highlighted source, history, blame, and downloads.

Readable change review

Unified and split diffs, image comparison, rename detection, anchors, and progressive loading.

Patches, not pull requests

Import a pasted or uploaded patch after a dry-run preview, and export any commit or comparison as git format-patch output.

Fork, cherry-pick, merge

Fork any repository you can read, then cherry-pick, revert, or merge from the browser — fast-forward where possible, a real three-way merge otherwise.

Wikis and releases

Markdown wikis kept in their own Git repository, and tag-backed releases with downloadable assets.

Issues, kept small

Numbered issues with Markdown, comments, labels, and one assignee. No boards, no sprints, no workflow engine.

Insights from Git alone

Per-language byte breakdowns, per-author commit counts, stars, and forks — computed from the repository, not a tracker.

Simple self-hosting

SQLite, system Git, Smart HTTP, OpenSSH, protected branches, deploy keys, mirrors, audit logs, and a single Docker image.

Extensible and legible

A sandboxed plugin API and SDK, a versioned REST API with OpenAPI, and an /llms.txt summary for AI tooling.
