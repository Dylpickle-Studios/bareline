Paper Trail

A small, durable record of decisions. Designed for quiet, deliberate work.

Interactive design preview. This GitHub Pages site demonstrates Bareline’s interface; cloning, pushing, accounts, and search require the self-hosted server.

The essentials, carefully made

Everything you need to live comfortably in Git.

Repository browsing

File trees, rendered README files, syntax-highlighted source, history, blame, and downloads.

Readable change review

Unified and split diffs, image comparison, rename detection, anchors, and progressive loading.

Simple self-hosting

SQLite, system Git, Smart HTTP, OpenSSH integration, and a single Docker image.

Small-team permissions

Public and private repositories, groups, collaborators, API tokens, SSH keys, and audit logs.

Search that respects privacy

Local SQLite indexing across repositories, files, commits, branches, tags, people, and docs.

Extensible by design

A permission-controlled plugin API, sandboxed runtime, SDK, example plugin, and playground.
